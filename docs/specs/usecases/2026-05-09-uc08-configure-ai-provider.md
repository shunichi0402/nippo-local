# Spec: UC08 外部 AI プロバイダを設定する

## 背景

日報や月報の下書き作成、文字起こし補助などでは、外部 AI API を利用したい場面がある。
一方で、API キーや送信データは機密性が高いため、利用可否、モデル、API キーを明示的に管理できる必要がある。

## 目的

- OpenAI (ChatGPT) と Anthropic (Claude) を外部 AI プロバイダ候補として設定できるようにする
- プロバイダごとにモデル ID と API キーを設定できるようにする
- API キーを安全に保管し、平文表示やログ出力を避ける
- 外部 API へ送信するデータ範囲をユーザーが確認できるようにする

## 対象ユーザー

- 外部 AI API の利用可否を管理する admin
- 外部 AI の補助を使って日報/月報作成や文字起こしを効率化したいユーザー

## スコープ

### やること

- OpenAI (ChatGPT) プロバイダ設定
- Anthropic (Claude) プロバイダ設定
- プロバイダごとの有効/無効切り替え
- プロバイダごとのモデル ID 設定
- プロバイダごとの API キー登録、更新、削除
- API キーの暗号化保存、マスク表示
- 接続テスト
- 外部 API 送信前の確認表示

### やらないこと

- 外部 API の利用料金管理
- プロバイダアカウントの作成、請求設定
- 外部 API キーの自動発行
- ユーザーごとの個別 API キー管理

## ユースケース

1. admin は設定画面で OpenAI (ChatGPT) を有効化し、モデル ID と API キーを保存する
2. admin は設定画面で Anthropic (Claude) を有効化し、モデル ID と API キーを保存する
3. admin は保存済み設定で接続テストを実行する
4. admin は不要になったプロバイダ設定を無効化または削除する
5. ユーザーは外部 API 実行前に送信対象データを確認する

## 仕様

### 入力

- `authUserId` (必須): ログイン済みユーザー ID
- `provider` (必須): `openai` または `anthropic`
- `enabled` (必須): `true` または `false`
- `displayName` (任意): 1-50 文字
- `modelId` (必須): 1-100 文字
- `apiKey` (登録、更新時必須): 1-500 文字

### 出力

- 設定保存成功時:
  - 設定 ID
  - provider
  - enabled
  - displayName
  - modelId
  - API キーのマスク済み表示
  - 更新日時
- 接続テスト成功時:
  - provider
  - modelId
  - 成功/失敗
  - 実行日時

API キーの平文は API レスポンスに含めない。

### バリデーション

- admin 以外は設定の作成、更新、削除、接続テストを実行できない
- `provider` は `openai/anthropic` 以外を拒否
- `modelId` は空文字不可
- `apiKey` は登録、更新時のみ受け取り、取得 API では返さない
- 同一 provider の有効設定は 1 件までとする
- 無効化時は API キーを保持するか削除するかを admin が選択できる

### エラー時の動作

- API キー保存失敗時は設定を更新しない
- 暗号化または復号に失敗した場合は外部 API 呼び出しを行わない
- 接続テスト失敗時は provider、modelId、時刻、エラー種別を記録し、API キー平文はログに残さない
- 外部 API 実行前に送信対象データを確認できない場合は実行しない

### セキュリティ要件

- API キーはサーバー側で暗号化して SQLite に保存する
- 暗号化鍵は環境変数または OS の秘密情報ストアから読み込み、`data/` やリポジトリには保存しない
- API キーは登録直後も再表示せず、末尾数文字などのマスク済み表示だけを返す
- API キーはブラウザの localStorage、sessionStorage、IndexedDB に保存しない
- API キー平文、外部 API リクエスト本文、外部 API レスポンス本文を通常ログに出力しない
- 設定の作成、更新、削除、接続テストは監査ログ対象とする

## 受け入れ条件

- [ ] admin が OpenAI (ChatGPT) の modelId と API キーを設定できる
- [ ] admin が Anthropic (Claude) の modelId と API キーを設定できる
- [ ] API キーが平文で再表示されない
- [ ] API キーが暗号化されて保存される
- [ ] user は外部 AI プロバイダ設定を作成、更新、削除できない
- [ ] 接続テストで API キー平文がログに出ない
- [ ] 外部 API 実行前に送信対象データを確認できる

## 確認方法

- 正常系: OpenAI と Anthropic の設定保存、接続テスト、無効化を確認
- 異常系: 不正 provider、空 modelId、接続失敗、暗号化鍵未設定を確認
- 認可系: user 権限で設定 API へアクセスして拒否されることを確認
- セキュリティ: API レスポンス、ログ、SQLite に API キー平文が残らないことを確認
