# Spec: UC06 月報の下書きを作成して編集する

## 背景

月報は日報より対象期間が長く、抜け漏れや重複が発生しやすい。
MVP では、指定月の日報を主入力にして構造化した下書きを作成できることを重視する。

## 目的

- 指定月の日報と記録を集約し、月報下書きを生成できるようにする
- 主な成果、継続課題、学び、次月予定の観点で編集可能にする
- 月報から元の日報/記録へ遡及できるようにする

## 対象ユーザー

- 月次の振り返りを短時間で作成したいユーザー

## スコープ

### やること

- 対象月選択
- 日報中心の候補抽出
- 月報テンプレート選択
- セクション別下書き作成
- OpenAI (ChatGPT) または Anthropic (Claude) による下書き生成補助
- 外部 AI 送信前の対象データ確認
- 編集、保存、Markdown 出力

### やらないこと

- KPI の自動算出
- 外部システムへの定期送信
- 複数メンバー統合月報

## ユースケース

1. ユーザーは対象月を指定して日報候補を読み込む
2. ユーザーは不足分として記録を追加選択する
3. ユーザーは月報テンプレートを選択する
4. ユーザーは必要に応じて OpenAI (ChatGPT) または Anthropic (Claude) で下書き生成を補助する
5. ユーザーはセクションごとに本文を編集する
6. ユーザーは月報を保存して Markdown 出力する

## 仕様

### 入力

- `authUserId` (必須): ログイン済みユーザー ID
- `targetMonth` (必須): `YYYY-MM`
- `selectedDailyReportIds` (推奨): 0 件以上
- `selectedRecordIds` (任意): 0 件以上
- `templateId` (任意): 未指定時は既定の月報テンプレート
- `sections` (任意): `achievements/ongoing_issues/learnings/next_month_plan`
- `generationProvider` (任意): `none/openai/anthropic`
- `modelId` (外部 AI 利用時必須): 設定済みモデル ID
- `draftBody` (任意): Markdown 形式
- `exportFormat` (任意): `markdown`

### 出力

- 下書き生成結果:
  - セクション別本文
  - 参照した日報 ID
  - 参照した記録 ID
  - 生成時刻
- 保存結果:
  - 月報 ID
  - 対象月
  - Markdown 本文
  - 参照一覧
  - 使用テンプレート ID
  - 使用テンプレート本文スナップショット

### バリデーション

- 未ログイン状態での下書き生成と保存を拒否
- `targetMonth` 未指定は生成不可
- 日報 0 件かつ記録 0 件では保存不可
- 他ユーザー所有の日報、記録を選択した場合は拒否
- `templateId` 指定時はログインユーザーが所有する月報テンプレートのみ利用可
- `generationProvider` が `openai/anthropic` の場合は対象 provider が有効で、API キーと modelId が設定済みであること
- 外部 AI 利用時は送信対象データの確認を必須とする
- 対象月外データを含む場合は警告を表示
- `draftBody` は 100000 文字を上限

### エラー時の動作

- 生成失敗時は候補選択状態を保持
- 保存失敗時は編集中本文を保持
- 他ユーザーの参照先が含まれる場合は認可エラーを返す
- 参照元削除済みの場合は欠損参照として明示
- 外部 AI 呼び出し失敗時は候補選択状態と編集中本文を保持し、手動編集へ戻れるようにする
- 出力失敗時は保存済み本文から再出力可能

## 受け入れ条件

- [ ] 指定月の日報を候補として取得できる
- [ ] 日報がない日の記録を追加候補として選択できる
- [ ] 月報テンプレートを選択して下書き生成に利用できる
- [ ] OpenAI (ChatGPT) または Anthropic (Claude) を選んで下書き生成を補助できる
- [ ] 外部 AI 利用時に送信対象データを事前確認できる
- [ ] 月報下書きを編集して保存できる
- [ ] Markdown 形式で出力できる
- [ ] 月報保存時に使用テンプレート ID と本文スナップショットが保存される
- [ ] 月報から元の日報/記録へ遷移できる
- [ ] 他ユーザー所有の日報、記録を参照できない

## 確認方法

- 正常系: 候補取得、テンプレート選択、編集、保存、再表示、出力
- 異常系: 対象月未指定、候補未選択、他ユーザーテンプレート指定、外部 AI 呼び出し失敗、参照欠損
- 跨月データが混ざるケースで警告表示を確認
