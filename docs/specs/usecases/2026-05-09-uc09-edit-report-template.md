# Spec: UC09 日報/月報テンプレートを編集する

## 背景

日報や月報に求められる構成は、ユーザーや運用先によって異なる。
固定テンプレートだけでは、実際の提出先や振り返りの観点に合わせにくいため、設定画面からテンプレートを編集できるようにする。

## 目的

- ユーザーが自分の日報/月報テンプレートを管理できるようにする
- 下書き生成時にテンプレートを選択できるようにする
- 保存済み日報/月報が、後からのテンプレート変更で意図せず変わらないようにする

## 対象ユーザー

- 日報や月報の構成を自分の提出先に合わせたいユーザー

## スコープ

### やること

- 日報テンプレートの作成、編集、削除
- 月報テンプレートの作成、編集、削除
- 種別ごとの既定テンプレート設定
- Markdown テンプレート本文の保存
- 利用可能なプレースホルダーの検証
- 下書き生成時のテンプレート選択

### やらないこと

- 複数ユーザー間でのテンプレート共有
- テンプレートのマーケットプレイス
- 複雑な条件分岐やスクリプト実行

## ユースケース

1. ユーザーは設定画面で日報テンプレートを作成する
2. ユーザーは設定画面で月報テンプレートを作成する
3. ユーザーは種別ごとの既定テンプレートを指定する
4. ユーザーは下書き生成時に利用するテンプレートを選択する
5. ユーザーは不要になったテンプレートを削除する

## 仕様

### 入力

- `authUserId` (必須): ログイン済みユーザー ID
- `type` (必須): `daily_report` または `monthly_report`
- `name` (必須): 1-80 文字
- `body` (必須): 1-50000 文字、Markdown 形式
- `isDefault` (任意): `true` または `false`

利用可能なプレースホルダー:

- `{{targetDate}}`
- `{{targetMonth}}`
- `{{records}}`
- `{{dailyReports}}`
- `{{sections}}`

### 出力

- 保存成功時:
  - テンプレート ID
  - ownerUserId
  - type
  - name
  - body
  - isDefault
  - 作成日時
  - 更新日時
- 一覧表示:
  - テンプレート ID、type、name、isDefault、更新日時

### バリデーション

- 未ログイン状態では作成、編集、削除を許可しない
- `type` は `daily_report/monthly_report` 以外を拒否
- `name` が空文字の場合は保存不可
- `body` が空文字の場合は保存不可
- 未定義プレースホルダーは警告し、保存前に修正できるようにする
- 種別ごとの既定テンプレートはユーザーごとに 1 件までとする
- 他ユーザー所有テンプレートの参照、編集、削除は禁止
- 下書き生成で利用済みのテンプレートを削除しても、保存済み日報/月報の本文とテンプレートスナップショットは削除しない

### エラー時の動作

- 保存失敗時は編集中の入力値を保持する
- 他ユーザー所有テンプレートへの操作は 403 を返す
- 既定テンプレートの更新に失敗した場合は既存の既定状態を維持する
- 削除失敗時は一覧表示を巻き戻す

## 受け入れ条件

- [ ] 日報テンプレートを作成、編集、削除できる
- [ ] 月報テンプレートを作成、編集、削除できる
- [ ] 種別ごとに既定テンプレートを 1 件設定できる
- [ ] 下書き生成時にテンプレートを選択できる
- [ ] 未定義プレースホルダーが警告される
- [ ] 他ユーザー所有テンプレートを参照、編集、削除できない
- [ ] テンプレート変更後も保存済み日報/月報の本文が自動変更されない

## 確認方法

- 正常系: 日報/月報テンプレートの作成、編集、既定設定、削除
- 異常系: 空 name、空 body、不正 type、未定義プレースホルダー
- 認可系: 他ユーザー所有テンプレートの参照、編集、削除を検証
- 参照系: テンプレート変更後も保存済み日報/月報の本文とスナップショットが変わらないことを確認
