# Spec: UC05 日報の下書きを作成して編集する

## 背景

日報作成では、当日の複数記録を整理して文章化する作業が重い。
MVP では自動生成の完成度より、候補抽出と編集しやすい下書き生成を重視する。

## 目的

- 指定日の記録から日報下書きを生成できるようにする
- ユーザーが候補選択と本文編集を行えるようにする
- Markdown で保存、出力し、元記録へ遷移できるようにする

## 対象ユーザー

- 毎日の日報作成時間を短縮したいユーザー

## スコープ

### やること

- 対象日選択
- 候補記録抽出
- 候補の採用/除外
- 日報テンプレート選択
- OpenAI (ChatGPT) または Anthropic (Claude) による下書き生成補助
- 外部 AI 送信前の対象データ確認
- 下書き編集
- Markdown 保存、出力

### やらないこと

- 自動投稿 (Slack、メール等)
- 高度な文章校正
- チーム承認ワークフロー

## ユースケース

1. ユーザーは対象日を指定して候補記録を取得する
2. ユーザーは日報テンプレートを選択する
3. ユーザーは候補を選択、並び替えして下書きを作る
4. ユーザーは必要に応じて OpenAI (ChatGPT) または Anthropic (Claude) で下書き生成を補助する
5. ユーザーは本文を編集して日報として保存する
6. ユーザーは日報から元記録を開いて根拠を確認する

## 仕様

### 入力

- 候補取得:
  - `authUserId` (必須): ログイン済みユーザー ID
  - `targetDate` (必須): `YYYY-MM-DD`
- 下書き生成:
  - `authUserId` (必須)
  - `targetDate` (必須)
  - `selectedRecordIds` (必須): 1 件以上
  - `templateId` (任意): 未指定時は既定の日報テンプレート
  - `sections` (任意): `work/findings/issues/next_actions`
  - `generationProvider` (任意): `none/openai/anthropic`
  - `modelId` (外部 AI 利用時必須): 設定済みモデル ID
- 保存、出力:
  - `authUserId` (必須)
  - `targetDate` (必須)
  - `selectedRecordIds` (必須): 1 件以上
  - `templateId` (任意): 使用した日報テンプレート ID
  - `draftBody` (必須): Markdown 形式
  - `exportFormat` (任意): `markdown`

### 出力

- 下書き生成結果:
  - セクション別本文
  - 参照記録一覧
  - 生成時刻
- 保存結果:
  - 日報 ID
  - 対象日
  - Markdown 本文
  - 参照記録 ID 一覧
  - 使用テンプレート ID
  - 使用テンプレート本文スナップショット

### バリデーション

- 未ログイン状態での下書き生成と保存を拒否
- `targetDate` 未指定は候補取得、下書き生成、保存不可
- 下書き生成または保存時に `selectedRecordIds` が空配列の場合は不可
- `selectedRecordIds` に他ユーザー所有記録が含まれる場合は拒否
- `templateId` 指定時はログインユーザーが所有する日報テンプレートのみ利用可
- `generationProvider` が `openai/anthropic` の場合は対象 provider が有効で、API キーと modelId が設定済みであること
- 外部 AI 利用時は送信対象データの確認を必須とする
- 参照記録が対象日と大きくずれる場合は警告を表示
- `draftBody` は 50000 文字を上限

### エラー時の動作

- 生成失敗時は候補選択状態を保持
- 保存失敗時は編集中本文を保持
- 出力失敗時は保存済み本文から再出力できる
- 他ユーザー記録が含まれる場合は対象 ID を伏せた認可エラーを返す
- 参照記録欠損時は欠損 ID を明示
- 外部 AI 呼び出し失敗時は候補選択状態と編集中本文を保持し、手動編集へ戻れるようにする

## 受け入れ条件

- [ ] 対象日の候補記録を取得できる
- [ ] 日報テンプレートを選択して下書き生成に利用できる
- [ ] 候補を選択、除外して下書きを生成できる
- [ ] OpenAI (ChatGPT) または Anthropic (Claude) を選んで下書き生成を補助できる
- [ ] 外部 AI 利用時に送信対象データを事前確認できる
- [ ] 生成後に本文を編集して保存できる
- [ ] Markdown 形式で出力できる
- [ ] 日報保存時に使用テンプレート ID と本文スナップショットが保存される
- [ ] 日報から元記録への参照を辿れる
- [ ] 他ユーザー所有記録を候補に追加できない

## 確認方法

- 正常系: 候補抽出、テンプレート選択、編集、保存、再表示、出力
- 異常系: 候補未選択、対象日未指定、他ユーザーテンプレート指定、外部 AI 呼び出し失敗、保存失敗時の復元
- 参照遷移: 日報から元記録を開けることを確認
