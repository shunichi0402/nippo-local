# Spec: UC03 音声と文字起こしを記録する

## 背景

タイピングが難しい場面では音声記録が有効であり、後から検索するために文字起こしも必要となる。
MVP では、アプリ内で録音を開始、停止し、音声だけの単体記録として保存できることを必須とする。
外部で作成済みの音声ファイルもアップロードして取り込めるようにする。

## 目的

- アプリ内で録音を開始、停止し、音声だけの単体記録として保存できるようにする
- 外部で作成済みの音声ファイルを取り込めるようにする
- 必要に応じて既存の記録へ音声を添付できるようにする
- 文字起こし本文を登録、編集し、検索可能にする
- 文字起こし生成方式と作成時刻を追跡可能にする

## 対象ユーザー

- 音声メモを日報作成の材料として使いたいユーザー

## スコープ

### やること

- アプリ内録音の開始、停止
- 外部音声ファイルのアップロード取り込み
- 音声だけの単体記録作成
- 既存記録への音声添付
- 音声再生
- 文字起こし本文の登録、更新
- 文字起こし方式の保存

### やらないこと

- 話者分離
- ノイズ除去
- 自動品質評価

## ユースケース

1. ユーザーはアプリ内で録音を開始、停止して音声だけの記録を保存する
2. ユーザーは外部で作成済みの音声ファイルをアップロードして音声記録として保存する
3. ユーザーは必要に応じて既存記録へ音声を添付する
4. ユーザーは文字起こし本文を手動で入力して保存する
5. ユーザーは文字起こしを修正して検索精度を上げる
6. ユーザーは元音声を再生して内容を確認する

## 仕様

### 入力

- 共通:
  - `authUserId` (必須): ログイン済みユーザー ID
  - `source` (必須): `recording` または `upload`
  - `recordingAction` (録音操作時必須): `start` または `stop`
  - `audioFile` (保存またはアップロード時必須): `m4a/mp3/wav/webm`、1 ファイル 100MB 以内
  - `transcriptText` (任意): 0-50000 文字
  - `transcriptMethod` (任意): `manual/local_model/external_api`
- 音声だけの単体記録作成:
  - `title` (任意): 0-120 文字
  - `targetDate` (必須): `YYYY-MM-DD`
  - `tags` (任意): 0-10 件、各 1-30 文字
  - `category` (任意): 0-30 文字
  - `project` (任意): 0-50 文字
- 既存記録への添付:
  - `recordId` (任意): 指定時は既存記録に音声を添付し、未指定時は音声だけの単体記録を作成する

### 出力

- 音声登録成功時:
  - 記録 ID
  - 音声添付 ID (UUID v7)
  - 相対パス
  - 保存ファイル名 (`<attachmentId>.<ext>`)
  - 元ファイル名 (アップロード時)
  - 長さ (取得可能な場合)
  - MIME type
- 文字起こし保存成功時:
  - 文字起こし ID
  - 本文
  - 方式
  - 作成日時
  - 更新日時

### バリデーション

- 音声形式、サイズ制限を厳格に適用
- 添付 ID は UUID v7 で発行する
- 保存ファイル名は `<attachmentId>.<ext>` とし、元ファイル名を直接使わない
- アップロード時の元ファイル名はメタデータとして保存する
- `source` が `upload` の場合は `audioFile` を必須とする
- 録音開始中の重複開始は拒否
- 録音停止時に保存可能な音声データがない場合は保存不可
- 音声だけの単体記録作成時は `targetDate` 必須
- `transcriptMethod` は定義済み値のみ許可
- `transcriptText` は 50000 文字超過不可
- `recordId` 指定時、存在しない `recordId` への関連付けは禁止
- `recordId` が他ユーザー所有の場合は録音、音声登録、文字起こし更新不可

### エラー時の動作

- 未ログイン状態では音声登録、文字起こし更新を許可しない
- 他ユーザー所有レコードへの録音、音声登録、文字起こし更新は 403 を返す
- 録音開始、停止に失敗した場合は再試行できる状態を維持する
- 外部音声ファイルのアップロード失敗時はレコードを作成しない
- 音声だけの単体記録作成失敗時はレコードを作成しない
- 文字起こし更新失敗時は直前保存値を保持
- 外部 API 利用時は送信対象データの確認ダイアログを表示
- エラーログに処理対象 ID と処理段階を記録

## 受け入れ条件

- [ ] アプリ内で録音を開始、停止し、音声だけの単体記録として保存できる
- [ ] 外部で作成済みの音声ファイルをアップロードして取り込める
- [ ] 添付 ID と保存ファイル名が UUID v7 ベースで作成される
- [ ] 既存記録へ音声を添付できる
- [ ] 保存した音声を再生できる
- [ ] 文字起こし本文を保存、更新できる
- [ ] 文字起こし方式が保存される
- [ ] 文字起こし本文が検索対象に含まれる
- [ ] 外部 API 利用時に送信内容の明示がある
- [ ] 他ユーザー所有レコードへの録音、音声登録、文字起こし更新が拒否される

## 確認方法

- 正常系: 録音開始、停止、外部音声ファイル取り込み、音声単体記録作成、既存記録への添付、再生、文字起こし作成、更新
- 異常系: 重複録音開始、音声なし停止、アップロード失敗、形式不正、サイズ超過、`transcriptMethod` 不正値
- 保存名: 保存ファイル名が `<attachmentId>.<ext>` になり、アップロード時の元ファイル名がメタデータに残ることを確認
- 認可系: 他ユーザー所有 `recordId` への録音、音声登録、文字起こし更新を検証
- 検索: 文字起こし語句で記録を検索
